Project Title:Customer Churn Analysis and Prediction
To reduce revenue loss from customer attrition, this project analyzes telecom customer data to find the drivers of churn and builds an explainable machine learning model that predicts at-risk customers, enabling targeted and cost-effective retention.


Objectives:
Understand churn patterns, build a KPI dashboard, compare predictive models, evaluate with recall, precision, F1 and PR-AUC, explain predictions with SHAP, quantify business impact with a cost-based threshold, deploy a Streamlit app.
